# Ethernet-remixes-GameCube-
Various STL files for W5500 on GameCube


These were remixed from Silverstee1 SP1ETH 
source: https://github.com/silverstee1/SP1ETH

In the STL folder you'll find STL files to make a W5500 SP12SP2-ETH with a SP2 stabilizer. You can use the small PCB from most angled SD2SP2 adapters as long as you wire to the correct pins. The first part has 2 versions but the only difference is the hole shape/size going towards the SP2 port.

I also made alterations for the W5500 to fit in the SP1ETH, but it is not currently supported in the SP1 port as of writing this.
